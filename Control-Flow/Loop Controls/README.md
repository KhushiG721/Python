# Loop Control Statements in Python

Loop control statements modify the normal flow of execution within loops. They allow a program to terminate a loop, skip the current iteration, or use a placeholder where code will be implemented later.

Python provides three important statements for these purposes:

- `break`
- `continue`
- `pass`
