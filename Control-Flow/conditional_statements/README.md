# Conditional Statements in Python

Conditional statements allow a Python program to make decisions based on whether a condition is `True` or `False`.

They are an important part of **control flow** because they determine which block of code should be executed.

---

## Topics Covered

- `if` statement
- `if-else` statement
- `if-elif-else` statement
- Nested `if` statements
- Conditions and Boolean expressions
- Comparison operators
- Logical operators
- Python indentation
