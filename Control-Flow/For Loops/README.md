# For Loops in Python

A `for` loop is used to repeatedly execute a block of code for each item in a sequence or iterable.

For loops are one of the fundamental concepts of Python control flow and are commonly used to process strings, lists, tuples, sets, dictionaries, ranges, and other iterable objects.
