# Python Input and Output

Input and output are fundamental concepts in Python.
The `input()` function is used to receive data from a user,
while the `print()` function is used to display information.

This section demonstrates basic input, output, formatting,
and simple input validation.

---

## Topics Covered

| Topic | Description |
|---|---|
| `input()` | Accept input from the user |
| `print()` | Display output |
| Type Conversion | Convert user input into required types |
| Formatting | Display values clearly |
| Validation | Check whether input is valid |

---

## Learning Objectives

By completing this section, I aim to understand:

- How to accept user input using `input()`
- How to display information using `print()`
- Why `input()` returns a string
- How to convert input into `int`, `float`, and other types
- How to format output using f-strings
- How to perform basic input validation
