# Python Data Types

Data types define the kind of value that can be stored and manipulated in Python.

This section demonstrates Python's built-in data types through practical examples,
including their characteristics, common operations, and type-checking techniques.

---

## Topics Covered

| Category | Data Types |
|----------|------------|
| Numeric | `int`, `float`, `complex` |
| Boolean | `bool` |
| Sequence | `str`, `list`, `tuple` |
| Set | `set` |
| Mapping | `dict` |
| Special | `NoneType` |

---

## Learning Objectives

By completing this section, I aim to understand:

- How Python represents different types of data
- The difference between mutable and immutable objects
- How to inspect an object's type using `type()`
- How to validate types using `isinstance()`
- Common operations supported by different data types
- When to use each built-in data type
