# Python Operators

Operators are symbols and keywords used to perform operations
on values and variables.

This section demonstrates the major types of operators available
in Python.

---

## Operator Categories

| Category | Purpose |
|---|---|
| Arithmetic | Perform mathematical calculations |
| Comparison | Compare two values |
| Logical | Combine or modify conditions |
| Assignment | Assign and update values |
| Membership | Check whether a value exists in a collection |
| Identity | Check whether two references point to the same object |
