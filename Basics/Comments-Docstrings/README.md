# 📝 Python Comments and Docstrings

Comments and docstrings are used to make Python code easier to understand, read, and maintain.

Comments help explain specific parts of the code, while docstrings are used to document modules, functions, classes, and methods.

---

## 📌 Comments

A comment is text written in the source code that Python does not execute.

A single-line comment starts with the `#` symbol.


Comments are useful for explaining:

- What a section of code does
- Why a particular approach is used
- Important implementation details
- Temporary notes during development

---

## 📖 Docstrings

A **docstring** is a string used to document Python code.

Docstrings are commonly used for:

- Modules
- Functions
- Classes
- Methods

---


## 💡 Comments vs Docstrings

| Feature | Comments | Docstrings |
|---|---|---|
| Syntax | `#` | `""" """` or `''' '''` |
| Main purpose | Explain code | Document code |
| Used for | Code explanations | Modules, functions, classes, methods |
| Stored by Python | No | Yes |
| Accessible using `__doc__` | No | Yes |
| Part of documentation | Usually no | Yes |

## 💡 Key Takeaways

- Comments are ignored by the Python interpreter.
- Single-line comments begin with `#`.
- Python does not have a dedicated multi-line comment syntax.
- Docstrings are used to document Python code.
- Docstrings can be written for modules, functions, classes, and methods.
- Function documentation can describe parameters and return values.
- Docstrings can be accessed through the `__doc__` attribute.
- Good comments explain useful information rather than obvious code.
- Clear documentation improves code readability and maintainability.
